¿Qué es el margen?

El chip calcula acc0 (respuesta al kernel X) y acc1 (respuesta al kernel Cruz) para cada imagen. El comparador hace:

comp = acc0 > acc1

El margen es la distancia al umbral:
— Para X: margin = acc0 − acc1 (quiero > 0)
— Para Cruz: margin = acc1 − acc0 (quiero > 0)

Un margen de 0 significa clasificación en el filo — cualquier perturbación podría causar un error. Un margen grande es robusto.

¿Por qué el mínimo importa más que el promedio?

El promedio para X es 36.5 — suena bien. Pero hay 3 imágenes X con margen 4, 5, 5. Esas son X con trazo grueso + desplazamiento + ruido.

Si el margen mínimo fuera ≤ 0, habría al menos una imagen mal clasificada.

El GA optimizó justamente para maximizar el mínimo margen — no el promedio. Eso garantiza que todas las imágenes pasan, incluso las más difíciles.

Cruz vs X — asimetría de dificultad: la Cruz tiene margen mínimo de 36 frente a 4 de la X. Las barras horizontales/verticales son geométricamente más distintas a lo que activa el kernel X que viceversa. La X con ruido puede confundirse parcialmente con una Cruz; la Cruz rara vez se confunde con una X.
6 casos representativos — clase X
Por qué la X perfecta tiene menos margen que la X con ruido óptima: el margen depende de cuánto activa cada kernel, no solo de que la forma sea clara. Una X limpia con desplazamiento −1 puede quedar mejor alineada con los fragmentos que una X centrada — el stride=2 de los fragmentos crea zonas de mayor cobertura.
6 casos representativos — clase Cruz
Cruz peor (margen=36) vs Cruz mejor (margen=76): la Cruz con grosor=2 desplazada sin ruido es la más difícil porque sus barras anchas ocupan columnas donde el kernel X también tiene pesos altos. Paradójicamente, la Cruz con ruido puede tener margen más alto si los píxeles aleatorios caen en zonas que el kernel X suprime.

Observación clave: la distribución de Cruz está completamente desplazada a la derecha. Ninguna Cruz tiene margen menor a 36, mientras que las X tienen una cola izquierda que llega hasta 4. Esto refleja que la X es la clase "difícil" — más variabilidad geométrica por las diagonales. Para un sistema más robusto habría que aumentar el margen mínimo de X, lo que requeriría más generaciones del GA o un dataset con más variaciones extremas.
